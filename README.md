# 📉 Customer Churn Analysis

## 📌 Project Overview
Customer churn is a major challenge for businesses, as retaining existing customers is more cost-effective than acquiring new ones.  
This project focuses on **Customer Experience (CX) Churn Analysis** to identify key factors influencing customer churn and to provide actionable insights for improving customer retention.

The analysis is performed using Python with data visualization and exploratory data analysis techniques.

---

## 🎯 Objectives
- Analyze customer data to identify churn patterns  
- Understand the impact of customer experience on churn  
- Compare churned vs non-churned customers  
- Provide business insights to reduce customer churn  

---

## 🛠️ Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

---

## 📂 Dataset Description
The dataset includes customer demographic details, service subscriptions, account information, and churn status.

### Key Attributes:
- Customer demographics (Gender, Senior Citizen, Partner, Dependents)
- Services used (Phone Service, Internet Service, Streaming Services)
- Account details (Tenure, Contract Type, Payment Method)
- Charges (Monthly Charges, Total Charges)
- Target variable: **Churn**

---

## 🔍 Analysis Performed
- Data cleaning and preprocessing  
- Handling missing values  
- Exploratory Data Analysis (EDA)  
- Churn distribution analysis  
- Service-wise churn comparison  
- Contract and tenure impact on churn  
- Visualization of churn patterns  

---

## 📊 Key Insights
- Customers with **month-to-month contracts** have higher churn rates  
- Customers with **shorter tenure** are more likely to churn  
- Certain services are strongly associated with churn behavior  
- Long-term contracts help improve customer retention
